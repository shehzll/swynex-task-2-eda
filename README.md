# Titanic Dataset – Exploratory Data Analysis

## Project Overview
This project explores the cleaned Titanic passenger dataset using Python, Pandas, NumPy, and Matplotlib.

## Objectives
- Calculate important statistics.
- Analyze passenger survival patterns.
- Compare survival rates between groups.
- Visualize age and fare distributions.
- Identify potential anomalies.

## Analysis Performed
- Dataset structure and descriptive statistics.
- Missing-value and duplicate checks.
- Passenger survival analysis.
- Survival rate comparison by sex.
- Age distribution analysis.
- Average fare comparison by survival status.
- Age-group analysis and outlier checks.

## Files Included
- `titanic_cleaned(1).csv` — cleaned dataset.
- `Task2_Exploratory_Data_Analysis.ipynb` — Python analysis notebook.
- `eda_charts.zip` — exported charts.

## Key Findings

1. **Overall Survival Rate:** Approximately 38.38% of passengers survived, while 61.62% did not survive.

2. **Survival Counts:** Out of 891 passengers, 342 survived and 549 did not survive.

3. **Survival by Sex:** The survival rate was 74.20% for female passengers and 18.89% for male passengers. Female passengers had a considerably higher survival rate in this dataset.

4. **Average Fare:** Passengers who survived paid an average fare of 48.40, compared with 22.12 for passengers who did not survive. This suggests an association between fare paid and survival.

5. **Survival by Age Group:** Children had the highest survival rate at 57.97%, followed by adults at 40.00%, teenagers at 42.86%, young adults at 35.33%, and seniors at 22.73%.

## Conclusion

The exploratory analysis identified differences in survival rates by sex and age group, as well as an association between fare paid and survival. The visualizations and statistics help summarize these patterns in the Titanic dataset. These findings show associations and do not establish causation.
